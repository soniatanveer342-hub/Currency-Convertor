💱 Currency Converter
A clean and simple Currency Converter web app built with HTML, CSS, and JavaScript. Instantly convert between different currencies with an easy-to-use interface.



🛠️ Built With

HTML5 — App structure
CSS3 — Styling and layout
JavaScript — Conversion logic and interactivity


✨ Features

💵 Convert between multiple currencies
🔄 Swap currencies with one click
🧮 Instant real-time calculation
🎨 Clean and minimal user interface


📁 Project Structure
currency-converter/
├── index.html       # Main HTML file
├── style.css        # Styles
└── script.js        # Conversion logic

🚀 How to Run

Download or clone this repository
Open index.html in your browser
No setup or internet connection required!


🧠 How It Works

User enters an amount
Selects the source currency (e.g. USD)
Selects the target currency (e.g. PKR)
The converted amount is calculated and displayed instantly
Swap button switches between the two selected currencies
